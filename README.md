Entry for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on [make.fun](https://make.fun): one funny line of text, at most 200 characters, judged pairwise by an AI comedy editor.

## The line

> My autocorrect changed 'I love you' to 'I owe you' — it understands my finances better than I do.

97 characters, 99 bytes. The entry text lives in `entry.txt` and is written by `main.ts` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to a local `output/` directory).

## Run it

```sh
node main.ts            # writes output/entry.txt
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts   # writes /tmp/out/entry.txt
```
